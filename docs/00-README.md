# OHRR App — Project Folder

This folder holds the working documents for the **Ohio House Rabbit Rescue (OHRR)** app project. Files are plain Markdown (`.md`) so they're easy to reference, edit, and eventually drop into a code repository.

## Contents

| File | What's in it |
|---|---|
| `00-README.md` | This index. |

## Project in one line

Design an app that supports **all** of OHRR's efforts — rescue, adoption, education, and their flagship fundraiser **Midwest BunFest**.
